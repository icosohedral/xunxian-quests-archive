# 寻仙任务资料库

一个整理、检索与阅读《寻仙》游戏任务内容的非官方资料库。

从小桑村初入仙途，到宁海、石塘、京城，再到那些已经有些模糊的副本、活动与旧日故事，这里希望把散落在游戏资源中的任务重新整理起来，让曾经走过的路、遇见的人和读过的对白都能再次被找到。

> 寻仙路远，旧事可寻。

## 在线访问

[quests.xunxian.wiki](https://quests.xunxian.wiki)

## 收录内容

资料库目前整理了 8,828 个任务，内容包括：

- 任务名称、等级、类型与所属地区；
- 接取人物、交付人物和相关 NPC；
- 接取对话、任务背景、途中提示与完成对话；
- 任务条件、目标和奖励；
- 前置任务、后续任务与相关任务；
- 对话中出现的敌人、人物和寻路目标。

有些任务在原始资料中没有完整文本，有些名称或关系也无法可靠确认。遇到这种情况，资料库会尽量保留原貌，不凭空补写内容。

## 可以怎样寻找

- **按名称搜索**：寻找记得名字或只记得几个字的任务。
- **按人物查找**：看看某位 NPC 曾经交付过哪些任务。
- **按地区浏览**：重温小桑村、宁海县、石塘县、京城等地的故事。
- **按类型筛选**：查看正传、支线、重复、系列、副本、活动等任务。
- **顺着任务关系阅读**：从一个任务继续查看它的前置、后续与相关任务。

## 为什么整理

《寻仙》的任务不只是升级途中的步骤，也记录着许多人物、地方和故事。随着版本变化，一些任务已经不容易再次遇见，很多对白和细节也渐渐难以查找。

这个资料库希望为这些内容留下一份方便阅读的索引。它不是攻略站，也不追求替玩家规划最快路线；更像是一册可以随时翻阅的任务旧档，供老玩家回忆，也供对游戏世界感兴趣的人慢慢探索。

## 关于资料

任务资料来自本地游戏资源的整理。资料库尽量保留原始名称与文本，并对人物、地区、目标、奖励和任务关系进行归类。

同一任务如果在资源中存在不同版本，会尽可能一并保留；无法确认的内部字段不会被强行解释。页面展示以便于阅读为目标，底层原始资料不会被直接改写。

## 项目说明

本项目由爱好者整理，用于《寻仙》任务资料的研究、检索与个人回顾，并非《寻仙》官方网站。

仓库不会提交原始游戏资源、完整任务数据库或本地资料文件。游戏名称、文字及相关内容的版权归其原权利人所有，请勿将资料用于商业用途。
